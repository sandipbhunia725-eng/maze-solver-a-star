# Maze Solver using A* Search Algorithm

AI Internship Project 1 — interactive A* pathfinding visualizer.

## Features
- Interactive NxN grid
- Add/remove walls by dragging
- Move Start and Goal cells
- A* shortest-path search
- Manhattan and Euclidean heuristics
- Search/path animation
- Random maze generation
- Visited-node, path-length and execution-time statistics
- Responsive UI

## Run
No installation is required.

1. Open `index.html` in a browser, or use VS Code Live Server.
2. Draw walls.
3. Click **Solve with A***.
4. Change the heuristic or grid size to experiment.

## A* Formula
`f(n) = g(n) + h(n)`

- `g(n)`: cost from Start to node n
- `h(n)`: estimated cost from n to Goal
- `f(n)`: total estimated cost
